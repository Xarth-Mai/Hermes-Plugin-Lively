## 实现取舍

- 使用 `ctx.state.data_dir` 和标准库 SQLite，不依赖未确认的 ctx.plugin_db 接口。
- 每个授权绑定使用独立预检路径，旧绑定的脚本不能替新绑定领取机会。
- “未回应”按模型机会计算；暂不声称掌握真实发送回执，不单独实现平台发送账本。
- 本版主动联系只验证 `in_process`；`host` 隔离模式的启用被明确拒绝。
- NianYu 只迁移已核查的表达与判断原则；频率和原生宿主职责以本项目约定为准。
